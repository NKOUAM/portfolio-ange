## 🚀 Lancer en local

### Prérequis
- Node.js ≥ 20.9
- npm

### Installation & démarrage

```bash
npm install
ng serve --open
```

→ Le portfolio s'ouvre sur **http://localhost:4200**

### Build production

```bash
ng build --configuration production
```

Les fichiers optimisés seront dans `dist/porfolio/`.
